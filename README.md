# IGCSE ICT Practical Skills — Complete Guide

A step-by-step guideline for IGCSE ICT students preparing for the **Paper 2** and **Paper 3** practical examinations (Cambridge International, Syllabus 0417).

---

## 📚 What You Will Learn

This guide covers every skill tested in the two ICT practical papers using:

| Software | Topics Covered |
|---|---|
| Microsoft Word | Document production, formatting, mail merge |
| Microsoft Access | Database creation, queries, forms, reports |
| Microsoft PowerPoint | Presentation design and formatting |
| Microsoft Excel | Spreadsheets, formulas, charts, data analysis |
| Microsoft Expression Web | Web page creation with HTML & CSS |

---

Paper 2 consists of three tasks completed in one 2½-hour session:

| Task | Software | Skills |
|---|---|---|

| Task B – Data Manipulation | Microsoft Access | Tables, queries, forms, reports |
| Task C – Presentations | Microsoft PowerPoint | Slides, transitions, master slides, notes |

## 🗂️ How to Use This Guide

1. Read the relevant guide **before** attempting a past paper.
2. Follow the numbered steps for each skill area.
3. Practice each skill on sample data before timing yourself.
4. Check the *Common Mistakes* sections in each guide to avoid losing marks.
5. Attempt full past papers under exam conditions (2½ hours per paper).

---

## 📝 General Exam Tips

- **Save your work every 5–10 minutes** and use the filename specified in the question.
- Always **read the whole task before starting** — later steps sometimes affect earlier ones.
- Use the **exact font names, sizes, and colours** stated in the question.
- **Spell-check** all text before submitting.
- When printing, check that output fits on the page as instructed (portrait/landscape, margins).
- Keep all source files (images, data files) in the same folder as your working document.
