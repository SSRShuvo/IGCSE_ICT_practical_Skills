# Paper 2 Task A — Word Processing with Microsoft Word

Microsoft Word is used in Paper 2 for **document production**. You will be given a source document or raw text and asked to format it to an exact specification.

---

## 1. Setting Up the Document

### 1.1 Page Size and Orientation
1. Go to **Layout** tab → **Size** → choose **A4**.
2. Go to **Layout** tab → **Orientation** → choose **Portrait** or **Landscape** as instructed.

### 1.2 Page Margins
1. Go to **Layout** tab → **Margins** → **Custom Margins…**
2. Enter the exact margin values (top, bottom, left, right) stated in the question.
3. Click **OK**.

### 1.3 Saving the File
1. Press **Ctrl + S** (or **File** → **Save As**).
2. Use the **exact filename** given in the question.
3. Save as **.docx** unless the question specifies a different format (e.g. .rtf).

---

## 2. Text Formatting

### 2.1 Font, Size, and Style
1. Select the text you want to format.
2. In the **Home** tab, use the **Font** group:
   - **Font name** drop-down — type or select the exact font (e.g. Arial, Times New Roman).
   - **Font size** box — type the exact size in points.
   - **B** for Bold, **I** for Italic, **U** for Underline.
3. Always check the question for the exact font name and size — marks are lost for incorrect fonts.

### 2.2 Font Colour
1. Select the text.
2. Click the arrow next to **Font Color** (the **A** with a colour bar) in the **Home** tab.
3. Choose **More Colors…** if an exact RGB or hex value is required.

### 2.3 Alignment
| Alignment | Shortcut |
|---|---|
| Left | Ctrl + L |
| Centre | Ctrl + E |
| Right | Ctrl + R |
| Justify | Ctrl + J |

### 2.4 Line Spacing
1. Select the paragraph(s).
2. **Home** tab → **Line and Paragraph Spacing** button → choose the spacing, or
3. **Home** tab → **Paragraph** dialog launcher (small arrow) → **Line spacing** → choose Single / 1.5 / Double / Exactly + value.

### 2.5 Paragraph Spacing
1. Select the paragraph(s).
2. **Home** tab → **Paragraph** dialog launcher.
3. Set **Spacing Before** and **Spacing After** to the values stated in the question.

---

## 3. Styles

### 3.1 Applying a Built-in Style
1. Place the cursor in the paragraph or select the text.
2. In the **Home** tab → **Styles** gallery, click the named style (e.g. Heading 1, Normal).

### 3.2 Modifying a Style
1. Right-click the style name in the **Styles** gallery.
2. Click **Modify…**
3. Change font, size, colour, spacing as required.
4. Click **OK** — all text using that style updates automatically.

### 3.3 Creating a New Style
1. Format a paragraph to the required specification.
2. In the **Styles** gallery, click the drop-down arrow → **Create a Style**.
3. Give it the exact name stated in the question.
4. Click **OK**.

---

## 4. Headers and Footers

1. Go to **Insert** tab → **Header** or **Footer** → **Edit Header / Edit Footer**.
2. Type the required text (e.g. your name, centre number, candidate number, date, filename).
3. To insert automatic fields:
   - **Insert** → **Quick Parts** → **Field** → choose `FileName`, `Date`, `Page`, etc.
4. Use the **Home** tab to format text inside the header/footer.
5. Double-click the main body to exit the header/footer area.

> **Common mistake:** Forgetting to include your name and candidate number in the header or footer as instructed.

---

## 5. Tables

### 5.1 Inserting a Table
1. Place the cursor where the table should appear.
2. **Insert** tab → **Table** → drag to select the required number of rows and columns, or choose **Insert Table…** and enter the numbers.

### 5.2 Formatting a Table
1. Click inside the table → use the **Table Design** and **Layout** contextual tabs that appear.
2. **Layout** tab → **Cell Size** group: set exact column widths and row heights.
3. **Table Design** tab: choose borders, shading, and table styles.

### 5.3 Merging and Splitting Cells
1. Select the cells to merge.
2. **Layout** tab → **Merge Cells**.
3. To split: select a cell → **Layout** tab → **Split Cells** → enter numbers.

### 5.4 Text Alignment in Cells
1. Select the cell(s).
2. **Layout** tab → **Alignment** group: choose from the nine alignment options (top-left, centre, bottom-right, etc.).

---

## 6. Images

### 6.1 Inserting an Image
1. **Insert** tab → **Pictures** → **This Device…** → navigate to the image file.
2. Click **Insert**.

### 6.2 Resizing an Image
1. Click the image to select it.
2. Drag a **corner handle** (keeps proportions) to resize, or
3. **Picture Format** tab → **Size** group: type exact width/height values.
4. To maintain aspect ratio, lock the ratio in the **Size** dialog (**Alt + Enter** or the dialog launcher).

### 6.3 Wrapping Text Around an Image
1. Select the image.
2. **Picture Format** tab → **Wrap Text** → choose **Square**, **Tight**, **Through**, **Top and Bottom**, or **Behind Text** as instructed.

### 6.4 Positioning an Image
1. Select the image.
2. **Picture Format** tab → **Position** → choose an absolute position, or
3. Drag the image to the required location.

---

## 7. Lists

### 7.1 Bulleted and Numbered Lists
1. Select the text to convert to a list.
2. **Home** tab → click **Bullets** (•) or **Numbering** (1. 2. 3.) button.
3. Click the drop-down arrow next to either button to change the bullet symbol or numbering format.

### 7.2 Changing List Indent Level
- Press **Tab** to increase indent (sub-list).
- Press **Shift + Tab** to decrease indent.

---

## 8. Mail Merge

Mail merge combines a **main document** (letter/label template) with a **data source** (Access table, Excel spreadsheet, or .csv file).

### 8.1 Start Mail Merge
1. Open the main document (or create a new one).
2. Go to **Mailings** tab → **Start Mail Merge** → choose **Letters** (or Labels, Envelopes, etc.).

### 8.2 Select Recipients (Data Source)
1. **Mailings** → **Select Recipients** → **Use an Existing List…**
2. Navigate to the data file (e.g. .accdb, .xlsx, .csv) and open it.
3. Select the correct table or sheet if prompted → **OK**.

### 8.3 Insert Merge Fields
1. Position the cursor where a field value should appear.
2. **Mailings** → **Insert Merge Field** → choose the field name (e.g. `FirstName`, `City`).
3. Merge fields appear as `«FirstName»`, `«City»`, etc.

### 8.4 Filter Records (if required)
1. **Mailings** → **Edit Recipient List**.
2. Click the drop-down arrow on a column header → **Filter…**
3. Set the criteria (e.g. City = "London") → **OK**.

### 8.5 Preview and Finish
1. **Mailings** → **Preview Results** to check the merge looks correct.
2. **Mailings** → **Finish & Merge** → **Print Documents…** or **Edit Individual Documents…**
3. Save the merged output using the filename given in the question.

> **Common mistakes:**
> - Wrong field name in the merge — the field in the document must exactly match the column heading in the data source.
> - Forgetting to apply a filter when the question asks you to print only certain records.

---

## 9. Columns

1. Select the text to format into columns (or place cursor for new columned text).
2. **Layout** tab → **Columns** → choose 2 or 3, or **More Columns…** for custom widths and spacing.
3. To create a column break: **Layout** → **Breaks** → **Column**.

---

## 10. Find and Replace

1. Press **Ctrl + H** to open Find and Replace.
2. Enter the text to find in **Find what** and the replacement text in **Replace with**.
3. Click **Replace All** (or **Replace** for individual occurrences).

---

## 11. Spell Check and Proofing

1. Press **F7** or go to **Review** tab → **Spelling & Grammar**.
2. Work through each suggestion, choosing **Change** or **Ignore**.
3. Make sure the document language is set correctly (**Review** → **Language** → **Set Proofing Language**).

---

## 12. Printing

1. Press **Ctrl + P** or **File** → **Print**.
2. Check the print preview to confirm layout (margins, orientation, page breaks).
3. Select the correct **printer**, **number of copies**, and **page range** as instructed.
4. For specific pages: type page numbers in the **Pages** box (e.g. `1,3` or `2-4`).

---

## Common Mistakes to Avoid

| Mistake | How to Avoid |
|---|---|
| Wrong font or size | Re-read the question; check the toolbar after applying |
| Missing header/footer content | Add name, centre/candidate number as instructed |
| Image not the correct size | Use exact values in the **Size** group, not drag |
| Mail merge fields with wrong spacing | Check spacing before and after each field |
| Saving with wrong filename | Copy the exact filename from the question |
| Text not fully justified | Select all body text and press **Ctrl + J** |
