# Paper 2 Task C — Presentations with Microsoft PowerPoint

Microsoft PowerPoint is used in Paper 2 for **creating and formatting presentations**. You will be given a content file and asked to produce a presentation that meets an exact specification.

---

## 1. Creating a New Presentation

1. Open PowerPoint → **File** → **New** → **Blank Presentation** (or open the provided file).
2. Save immediately: **File** → **Save As** → use the **exact filename** from the question.
3. Save as **.pptx** unless a different format is specified.

---

## 2. Slide Layout and Design

### 2.1 Applying a Slide Layout
1. Click the slide thumbnail in the **Slides** panel.
2. **Home** tab → **Layout** → choose the layout (Title Slide, Title and Content, Blank, etc.) as specified.

### 2.2 Applying a Theme or Design
1. **Design** tab → **Themes** gallery — hover to preview.
2. Click a theme to apply it to all slides.
3. To apply to only selected slides: right-click the theme → **Apply to Selected Slides**.

### 2.3 Setting Slide Size
1. **Design** tab → **Slide Size** → choose **Standard (4:3)** or **Widescreen (16:9)**, or
2. **Custom Slide Size…** → enter exact width and height in cm.

---

## 3. Slide Master

The Slide Master controls the consistent appearance of all slides. Always modify the Slide Master before adding content, so changes apply throughout the presentation.

### 3.1 Opening Slide Master View
1. **View** tab → **Slide Master**.
2. The top slide in the left panel is the **main Slide Master**; the slides below are layouts.
3. Changes to the main Slide Master affect all layouts.

### 3.2 Adding a Logo or Image to Every Slide
1. In Slide Master view, click the **main Slide Master** (top slide).
2. **Insert** tab → **Pictures** → **This Device…** → select the image file.
3. Resize and position the image as specified.
4. **Slide Master** tab → **Close Master View**.

### 3.3 Setting Background Colour on All Slides
1. In Slide Master view, click the main Slide Master.
2. **Slide Master** tab → **Background Styles** → **Format Background…**
3. Choose **Solid fill**, **Gradient fill**, **Picture or texture fill**, or **Pattern fill**.
4. Set the exact colour (use **More Colors…** for RGB/hex values).
5. Click **Apply to All** if prompted (stay in Master view so it applies to all layouts).

### 3.4 Adding a Footer, Date, or Slide Number to Every Slide
1. In Slide Master view or normal view: **Insert** tab → **Header & Footer**.
2. Tick **Date and time** (choose fixed or automatic), **Slide number**, and/or **Footer**.
3. Type footer text in the **Footer** box.
4. Click **Apply to All**.

### 3.5 Changing Font on All Slides via Slide Master
1. In Slide Master view, select the main Slide Master.
2. Click the title placeholder → select all title text → change font in **Home** tab.
3. Repeat for the body text placeholder.
4. Close Master View.

---

## 4. Adding and Editing Text

### 4.1 Adding Text to a Placeholder
1. Click the text placeholder on a slide (e.g. "Click to add title").
2. Type or paste the text.

### 4.2 Inserting a Text Box
1. **Insert** tab → **Text Box**.
2. Draw the text box on the slide and type.

### 4.3 Formatting Text
1. Select the text.
2. Use the **Home** tab: font name, size, Bold (**Ctrl + B**), Italic (**Ctrl + I**), Underline (**Ctrl + U**), colour.
3. To change text colour: **Home** → **Font Color** drop-down.

### 4.4 Bullet Points
1. Select the text in a content placeholder.
2. Bullets are applied automatically; change style via **Home** → **Bullets** drop-down.
3. To increase/decrease indent level: **Tab** (increase) / **Shift + Tab** (decrease).

---

## 5. Adding Images

### 5.1 Inserting an Image
1. **Insert** tab → **Pictures** → **This Device…** → select the image.
2. Click **Insert**.

### 5.2 Resizing an Image
1. Click the image to select it.
2. Drag a **corner handle** to resize proportionally, or
3. **Picture Format** tab → **Size** group: enter exact **Height** and **Width** values.
4. Tick **Lock aspect ratio** in the **Size** dialog if required.

### 5.3 Positioning an Image
1. **Picture Format** tab → **Align** → choose alignment relative to slide (Align Left, Centre, etc.).
2. Or drag the image; use the smart guides (orange dashed lines) to align precisely.

### 5.4 Layering Objects
- **Picture Format** or **Shape Format** → **Bring Forward** / **Send Backward**.

---

## 6. Adding Shapes and Drawing Objects

1. **Insert** tab → **Shapes** → click or drag the required shape.
2. Right-click the shape → **Add Text** to add text inside.
3. **Shape Format** tab → **Shape Fill**, **Shape Outline**, **Shape Effects**.

---

## 7. Transitions

Transitions control the animation between slides.

### 7.1 Applying a Transition to All Slides
1. **Transitions** tab → **Transition to This Slide** gallery — click a transition.
2. Click **Apply to All** to apply the same transition to every slide.

### 7.2 Setting Transition Duration
- **Transitions** tab → **Duration** box: type the time in seconds.

### 7.3 Setting Slide Advance
- **Transitions** tab → **Advance Slide** section:
  - **On Mouse Click** — slide advances when clicked.
  - **After** — slide advances automatically after a set time (e.g. `00:05.00` for 5 seconds).

---

## 8. Animations

Animations control how individual objects appear on a slide.

### 8.1 Adding an Animation to an Object
1. Click the object (text box, image, shape).
2. **Animations** tab → **Animation** gallery → click the animation (e.g. Appear, Fade, Fly In).

### 8.2 Animation Start Options
- **On Click** — plays when you click.
- **With Previous** — plays at the same time as the previous animation.
- **After Previous** — plays automatically after the previous animation finishes.

### 8.3 Animation Order
- **Animations** tab → **Animation Pane** — shows all animations in order.
- Drag items to reorder, or use the up/down arrows.

### 8.4 Removing an Animation
1. Click the object.
2. **Animations** tab → **Animation** gallery → **None**.

---

## 9. Hyperlinks

### 9.1 Creating a Hyperlink on a Slide
1. Select the text or object to hyperlink.
2. **Insert** tab → **Link** (or press **Ctrl + K**).
3. Choose:
   - **Existing File or Web Page** — type/paste a URL.
   - **Place in This Document** — link to another slide.
   - **E-mail Address** — creates a mailto link.
4. Click **OK**.

---

## 10. Speaker Notes

1. In Normal view, click the **Notes** panel below the slide (or **View** → **Notes Page**).
2. Type the speaker notes for each slide.
3. Notes are not visible during the presentation but can be printed.

---

## 11. Slide Numbering and Order

### 11.1 Adding Slide Numbers
1. **Insert** → **Header & Footer** → tick **Slide number** → **Apply to All**.
2. To start from a number other than 1: **Design** → **Slide Size** → **Custom Slide Size…** → set **Number slides from**.

### 11.2 Reordering Slides
1. In **Slide Sorter** view (**View** → **Slide Sorter**), drag slides to reorder them.
2. Or in Normal view, drag slide thumbnails in the left panel.

### 11.3 Deleting a Slide
1. Right-click the slide thumbnail → **Delete Slide**.

### 11.4 Duplicating a Slide
1. Right-click the slide thumbnail → **Duplicate Slide**.

---

## 12. Printing the Presentation

### 12.1 Printing Slides
1. **File** → **Print**.
2. Under **Settings**, choose what to print:
   - **Full Page Slides** — one slide per page.
   - **Handouts** — multiple slides per page (2, 3, 4, 6, or 9 per page).
   - **Notes Pages** — slides with speaker notes.
   - **Outline** — text outline only.
3. Set **Color / Greyscale / Pure Black and White** as instructed.
4. Click **Print**.

### 12.2 Exporting as PDF
1. **File** → **Save As** → change file type to **PDF**.
2. Or **File** → **Export** → **Create PDF/XPS**.

---

## 13. Setting Up a Slide Show

1. **Slide Show** tab → **Set Up Slide Show**.
2. Choose show type: **Presented by a speaker** (full screen), **Browsed by an individual** (window), or **Browsed at a kiosk** (loops automatically).
3. Set slide range if required.
4. Click **OK**.

---

## Common Mistakes to Avoid

| Mistake | How to Avoid |
|---|---|
| Logo/image not on every slide | Add it via the Slide Master, not manually on each slide |
| Wrong slide dimensions | Check **Design → Slide Size** before adding content |
| Transition not applied to all slides | Click **Apply to All** in the Transitions tab |
| Speaker notes on wrong slide | Check the slide number in the Notes pane before typing |
| Animation plays in wrong order | Check the Animation Pane and reorder as needed |
| Saving with wrong filename | Copy the exact filename from the question |
| Images pixelated or distorted | Resize using corner handles to maintain aspect ratio |
